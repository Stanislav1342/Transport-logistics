# ПУЛЬС — Транспортная логистика

Единый корпоративный веб-портал автоматизации транспортной логистики ФК «ПУЛЬС» (РЦ Черная Грязь).

Подробное техническое описание архитектуры, объединенных модулей (`ОПТ: Графики РК + Заявки` и `Температурные графики Advantum`), ролевой модели доступа (RBAC) и ограничений корпоративной среды находится в файле **[PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)**.
